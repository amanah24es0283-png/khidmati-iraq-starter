# AI Usage Report

## 1. AI Tool Used

The main artificial intelligence tool used during the development and documentation of the Khidmati Iraq project was:

- ChatGPT

## 2. Tasks Where AI Was Used

ChatGPT was used as an assisting tool during the project for:

- Understanding the existing project structure and its main components.
- Explaining technical errors encountered during environment setup.
- Assisting with troubleshooting installation and compatibility problems.
- Explaining Git and GitHub commands and helping verify repository status.
- Reviewing project documentation and identifying missing documentation requirements.
- Organizing technical reports and project documentation.
- Reviewing project requirements and comparing completed work with required deliverables.
- Improving the wording and structure of technical documentation.

## 3. Examples of Prompts Used

Examples include:

- "اشرحلي هذا الملف بالتفصيل."
- "شنو المشكلة بهذا الخطأ؟"
- "هل هذا الشغل صحيح؟"
- "راجع المشروع وشوف شكد خلصنا منه."
- "شنو باقي من متطلبات المشروع؟"

## 4. Suggestions or Outputs Accepted

AI-assisted outputs were accepted after review, including explanations of project structure, troubleshooting guidance, documentation organization, technical report wording, requirement checklists, and Git/GitHub workflow guidance.

## 5. Suggestions or Outputs Not Accepted

AI suggestions were not treated as automatically correct. Any suggestion that did not match the actual project files, requirements, or observed results was not adopted.

## 6. Errors or Limitations Produced by AI

AI may misunderstand the current state of a repository or development environment when it does not have direct access to the latest files. Therefore, project status, test results, required files, and implementation details were checked against the actual repository and documentation.

## 7. How the Results Were Verified

Verification was performed by checking the actual GitHub files, reviewing project documentation, comparing the work with the training requirements, checking Git/GitHub status, and reviewing documented test results.

## 8. What the Student Learned

Using AI as an assisting tool helped develop practical skills in reading an existing software project, troubleshooting technical errors, working with Git and GitHub, understanding backend, database, API and testing concepts, organizing documentation, and evaluating AI-generated suggestions.

## 9. Modifications Made by the Student

AI assistance was reviewed and adapted to the actual project. The student decided which suggestions to use, modified documentation to reflect the actual work, and verified technical information against the project environment and repository.

## 10. Parts Not Dependent on AI

The student remained responsible for executing project commands, managing the development environment and GitHub repository, reviewing project files, following project requirements, checking actual errors, deciding which suggestions were appropriate, and verifying final results.

## 11. Responsible Use of AI

AI was used as an assisting and learning tool rather than as a replacement for understanding or verification. Final decisions, project management, verification, testing, and documentation were reviewed by the student.

## Conclusion

ChatGPT contributed to understanding the existing project, troubleshooting development issues, organizing documentation, and reviewing project requirements. AI outputs were treated as suggestions requiring verification, while the student remained responsible for implementation, testing, decisions, and final deliverables.
